\# Scripts



Скрипты двух видов:



\## Стартовые скрипты эмулятора (`.emu`)



Наборы команд эмулятора. Выполняются через `--script`.



\- `start\_simple.emu` — только успешные команды.

\- `start\_with\_errors.emu` — включает ошибки; ошибочные строки

&#x20; пропускаются, но сообщение выводится.



\## Скрипты реальной ОС (`.bat`, `.sh`)



Запускают эмулятор с разными наборами параметров.



| Файл                  | Параметры                                       |

|-----------------------|-------------------------------------------------|

| `run\_minimal.bat/.sh` | без параметров (GUI)                            |

| `run\_with\_script.\*`   | `--vfs`, `--script` (GUI + автопроигрывание)    |

| `run\_console.\*`       | `--vfs`, `--script`, `--no-gui` (консоль)       |
