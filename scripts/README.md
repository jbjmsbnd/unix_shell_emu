# Scripts

Скрипты двух видов: стартовые скрипты эмулятора (`.emu`) и скрипты
реальной ОС (`.bat`, `.sh`), которые запускают эмулятор с нужными
параметрами.

## Генератор тестовых VFS

`make_vfs.py` создаёт три zip-архива в `scripts/vfs/`:

- `minimal.zip` — один файл в корне,
- `several.zip` — несколько файлов в разных папках,
- `deep.zip` — минимум 3 уровня вложенности.

Архивы **не коммитятся в git** (`*.zip` в `.gitignore`). Запуск:

```cmd
python scripts\make_vfs.py
```

## Стартовые скрипты эмулятора (`.emu`)

| Файл                        | Назначение                                  |
|-----------------------------|---------------------------------------------|
| `start_simple.emu`          | базовые команды без VFS                     |
| `start_with_errors.emu`     | ошибочные строки без VFS                    |
| `start_minimal.emu`         | команды на минимальном VFS                  |
| `start_several.emu`         | команды на VFS с несколькими файлами        |
| `start_deep.emu`            | команды на глубоко вложенном VFS            |
| `start_all_commands.emu`    | все команды этапов 1–4, включая ошибки      |

## Скрипты реальной ОС

### Запуск без VFS (этап 2)

| Файл                  | Параметры                                       |
|-----------------------|-------------------------------------------------|
| `run_minimal.bat/.sh` | без параметров (GUI)                            |
| `run_with_script.*`   | `--vfs`, `--script` (GUI + автопроигрывание)    |
| `run_console.*`       | `--vfs`, `--script`, `--no-gui` (консоль)       |

### Запуск с тестовыми VFS (этап 3)

| Файл                       | VFS           | Режим  |
|----------------------------|---------------|--------|
| `run_vfs_minimal.bat/.sh`  | `minimal.zip` | GUI    |
| `run_vfs_several.bat/.sh`  | `several.zip` | GUI    |
| `run_vfs_deep.bat/.sh`     | `deep.zip`    | GUI    |
| `run_vfs_all.bat/.sh`      | `deep.zip`    | консоль (все команды этапов 1–4) |

Все `run_vfs_*` сначала вызывают `make_vfs.py`, чтобы zip-архивы
существовали.
