# Unix Shell Emulator (VFS)

Эмулятор командной оболочки UNIX-подобной ОС с виртуальной
файловой системой. Реализован на Python с графическим
интерфейсом на Tkinter.

## Требования

- Python 3.10+
- Tkinter (входит в стандартную поставку Python для Windows)

## Установка

```cmd
python -m venv .venv
.venv\Scripts\activate
python -m pip install -U pytest
```

## Запуск

```cmd
run.bat
```

или

```cmd
python -m src.main
```

## Тесты

```cmd
python -m pytest
```

## Структура


## Поддерживаемые команды

| Команда | Аргументы | Описание                            |
|---------|-----------|-------------------------------------|
| `ls`    | до 1      | вывести список файлов (заглушка)    |
| `cd`    | до 1      | сменить каталог (заглушка)          |
| `exit`  | нет       | завершить работу эмулятора          |

Переменные окружения хоста раскрываются через `os.path.expandvars`
(например, `ls $HOME`).
